First run has no league panels, no sideline and no empty-plays line: the user has nothing to call yet, so the two ways in are the only play cards, stacked full width on a phone. There is no Join or Create button elsewhere; the cards are the way in.Create a league leads: it is the page's one filled button and wears the cursor frame. Join with a code is a plain card. Both are links to their own pages. The cards' lock-line slot is empty so nothing imitates a lock time.The promise copy (free to play, fantasy and/or pick'em, invite code, draft when friends are in) is said once, in the intro paragraph; the cards and steps say something else. No count badge: it would count choices, not things owed.The mock draft and the Waiver Wire column are public: they work without a league.
