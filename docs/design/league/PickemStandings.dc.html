The Standings section reuses the PickemOnly board's table and 18-cell heat strip: the viewer row is Play-blue with an arrow (not a cursor), ranks are plain figures with no medal colours, Trend is a 16px pixel arrow (12 to 14px wide) in Ink with its sr word, and the heat strip uses Frame color so green stays reserved. Straight up drops the Correct column (it always equals Points) and the 10-cell accuracy bars: Accuracy is the percent alone, right-aligned, so the same figure is not drawn twice; the table keeps one header row of column headers (th scope=col) and a row header per team (th scope=row), and the 9 columns match the 9 cells of every row. A one-line legend above the tiles states how the heat strip is drawn: each square is a week, fill height is that week against the team's own best week (in quarters, not against the league's best), a ringed square is the best week (every tied best week is ringed), an empty square is a week not yet played. Ties read T-3 and the next rank skips to 5.Heat strip (Critique 10 item 8): each team's strip is one labelled image, role=img, with the full sentence as its name (for example 'Weekly points, weeks 1 to 7: 9, 10, 7, 10, 7, 8, 1; best weeks 2 and 4'), and its 18 cells are aria-hidden, so a screen reader hears one sentence per row instead of eighteen. A tied best week is named in the sentence ('best weeks 2 and 4', or 'best week 3' when there is one) and every tied week wears the ring; the 'Best week' tile follows the same rule for the viewer.Commissioner settings (fantasy variant) sits above the sections control, as the product mounts it: one collapsed row with 'Pick'em on', Straight up and a ghost 'Edit' ('Hide' when expanded; the expanded panel is on the States sheet). The Picks and Standings control is one tab stop (selected option tabindex 0, the other -1).Wk 7 counts the Thursday game only (PIT @ CLE is the one final): Darkness Falls picked PIT, so 1 point; Pending is the picks still in play (8 live games carry 91 picks, 5 open games 31, 122 in all; JAX @ LAR is live, so none of its picks is decided): 8 for the viewer. No cursor and no filled action on this section: the cursor belongs to Picks (ARI at SF still needs a pick), and the sections control keeps the selected Standings state with Play-blue, an arrow and the word. The product's Season switch only draws when the page passes more than one season, so it is absent. Picks save on tap (Critique 10), so no batch-save button or bar exists on any Pick'em section.
