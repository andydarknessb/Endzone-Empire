Considered, not built

  • Click-to-sort column headers. The Sort select already covers every key; revisit with usage data.
  • Hiding IR players from the drop pick. The roster read carries no slot. Dropping an IR player frees no spot, so the add fails and the existing undo-drop puts the player back.
  • A combined add-and-drop endpoint. The client already drops, adds, and undoes the drop when the add fails (useAddPlayer); one transaction is a server ticket of its own.
  • Merging the app bar's global player search with the page search. App-wide, not a Players page call.
